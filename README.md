# ASTRO-RaspberryPi_Object_Detection_system
# ASTRo – Assurance of Safety for Transport and Road Operations

ASTRo is an AI-powered Raspberry Pi road safety system that performs:

- Real-time object detection using YOLOv8
- Human detection for road safety
- LED alert triggering through GPIO
- Live camera feed processing
- Video recording with detection bounding boxes
- Automatic cloud upload to Google Drive using rclone

---

# Features

Raspberry Pi Camera Integration

YOLOv8 Object Detection

GPIO LED Alert System

Real-time Video Processing

Automatic Video Recording

Automatic Google Drive Upload

---

# Hardware Used

- Raspberry Pi 4
- Raspberry Pi Camera Module
- Breadboard
- LED
- Resistor (220Ω)
- Jumper wires

---

# Software Stack

- Python
- OpenCV
- YOLOv8 (Ultralytics)
- Picamera2
- rclone
